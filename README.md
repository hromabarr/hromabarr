## About

I am a full stack developer who builds software for real businesses and the infrastructure that runs it. My work spans **TypeScript and Node.js applications**, **AI agents and automation**, and **self-hosted deployments**, with a strong focus on code that is simple, reproducible, and easy for other engineers to pick up.

On the application side, I build ERPs, channel managers, client portals and websites for small businesses, backed by PostgreSQL and deployed on Cloudflare Workers or my own servers. On the infrastructure side, I run services on Raspberry Pi and Docker Compose stacks that deploy cleanly on home servers, NAS systems, and Linux hosts.

I apply **LLMs** where they save people time: assistants that answer customers on the web and WhatsApp, a RAG knowledge base over company documents, a local desktop agent that controls apps and the browser, and daily briefings that cross calendar, email and tasks. I approach every project with a product engineering mindset: understand the user, keep the system simple, automate what repeats, and document what matters.

<summary><b>CRONO</b> — Native Swift Application for Apple Platforms</summary>

<br/>

A native Swift application built with a production-style engineering setup: declarative project generation, a dedicated test suite, automated CI workflows, and versioned design assets.

| Attribute | Details |
|:---|:---|
| **Stack** | ![](https://img.shields.io/badge/Swift-0d1117?style=flat-square&logo=swift&logoColor=a78bfa) ![](https://img.shields.io/badge/Xcode-0d1117?style=flat-square&logo=xcode&logoColor=a78bfa) ![](https://img.shields.io/badge/XcodeGen-0d1117?style=flat-square&logo=apple&logoColor=a78bfa) ![](https://img.shields.io/badge/XCTest-0d1117?style=flat-square&logo=apple&logoColor=a78bfa) ![](https://img.shields.io/badge/GitHub%20Actions-0d1117?style=flat-square&logo=githubactions&logoColor=a78bfa) |
| **Scale** | 43+ commits across app, test, and design modules |
| **Performance** | Native Swift build with automated pipeline validation on every push |
| **Security** | Generated Xcode project via `project.yml`, avoiding merge conflicts and drift in committed project files |
| **Impact** | Maintainable codebase structured for iteration, testing, and collaboration |
| **Repository** | [github.com/hromabarr/CRONO](https://github.com/hromabarr/CRONO) |

CRONO is organized like a professional app codebase rather than a prototype. The Xcode project is generated from a declarative `project.yml`, which keeps configuration reviewable and reproducible. Application code lives in its own module alongside a dedicated `CronoTests` target, and GitHub Actions workflows run on the repository so regressions are caught before they reach the main branch. Design assets are versioned in the same repository, keeping product, design, and code in sync.

</details>

<summary><b>DockerHytaleServer</b> — Containerized Dedicated Game Server Deployment</summary>

<br/>

A ready-to-deploy Docker Compose configuration for running a dedicated Hytale server on any Docker host, optimized for ZimaOS and CasaOS home servers.

| Attribute | Details |
|:---|:---|
| **Stack** | ![](https://img.shields.io/badge/Docker-0d1117?style=flat-square&logo=docker&logoColor=a78bfa) ![](https://img.shields.io/badge/Docker%20Compose-0d1117?style=flat-square&logo=docker&logoColor=a78bfa) ![](https://img.shields.io/badge/Java%2025-0d1117?style=flat-square&logo=openjdk&logoColor=a78bfa) ![](https://img.shields.io/badge/Linux-0d1117?style=flat-square&logo=linux&logoColor=a78bfa) ![](https://img.shields.io/badge/CasaOS%20%2F%20ZimaOS-0d1117?style=flat-square&logo=homeassistant&logoColor=a78bfa) |
| **Scale** | Single-file deployment portable across NAS systems, home servers, and Ubuntu hosts |
| **Performance** | Java 25 runtime with preconfigured UDP networking on port 5520 |
| **Security** | Encrypted session persistence for server authentication; no proprietary binaries bundled |
| **Impact** | Turns a manual server setup into a one-step import for self-hosters |
| **Repository** | [github.com/hromabarr/DockerHytaleServer](https://github.com/hromabarr/DockerHytaleServer) |

DockerHytaleServer packages everything needed to run a dedicated server into a single Compose file: a Java 25 environment, persistent volumes for world data, an interactive TTY console for administration, and preconfigured UDP ports. The documentation walks operators through device-based authentication, encrypted session persistence, and safe console detachment, and is fully bilingual in English and Spanish to serve a wider community of self-hosters.

</details>
